## Brand & Style

The design system establishes a high-precision, mission-critical Decision Support System (Sistem Pendukung Keputusan) tailored for executive leaders, urban planners, and agricultural engineers in the Karo Regency Government (Pemerintah Kabupaten Karo). The design aesthetic combines an institutional command center atmosphere with refined modern data engineering interfaces. It projects authority, operational transparency, analytical precision, and administrative clarity.

The visual direction merges **Command Center Tech** with **Subtle Glassmorphism and Controlled Luminosity**. Deep slate-void substrates eliminate visual fatigue during sustained spatial analysis, while disciplined neon gradient accents direct cognitive focus toward multi-criteria infrastructure prioritization. The interface balances high-density spatial informatics (GIS parameters, budget distributions, logistics network readiness) with clean visual hierarchies suited for formal Indonesian public sector operations (GovTech).

## Colors

The palette is engineered around deep spatial depths and four thematic categorical gradients representing strategic infrastructure pillars and critical alerts:

- **Base Substrate (`#070B14`)**: Void Canvas. Provides an absolute low-luminance canvas that minimizes eye strain and accentuates contextual glowing surfaces.
- **Surface Elevation (`#0E1424`)**: Command Card Surface. A desaturated navy container tier with calibrated 1px borders (`rgba(255, 255, 255, 0.08)`) and controlled edge dissipation.
- **Pillar 1: Agribisnis & Konektivitas (`#10B981` → `#14B8A6`)**: Emerald to Teal. Applied to primary agricultural arterial routes, export yields, and verified feasibility scores.
- **Pillar 2: Rekayasa & Infrastruktur (`#3B82F6` → `#6366F1`)**: Blue to Indigo. Represents engineering feasibility, structural surface grading, civil road classifications, and spatial geo-nodes.
- **Pillar 3: Efisiensi Anggaran & Logistik (`#F59E0B` → `#F97316`)**: Amber to Orange. Reserved for municipal capital allocations, fiscal return-on-investment, and supply chain continuity indicators.
- **Kondisi Kritis & Risiko (`#EF4444` → `#EC4899`)**: Crimson to Magenta. Dedicated to environmental hazards, volcanic exclusion zones (Gunung Sinabung risk maps), structural failure warnings, and priority intervention vetoes.
- **Detail Analysis Surface (`#F8FAFC`)**: High-contrast off-white sheet accent used strictly for focused deep-dive drawers, formal administrative export dossiers, and audit trail panels to maintain official government documentation aesthetics.

## Typography

Typography establishes an unequivocal distinction between cognitive narrative processing and raw metric analysis:

- **Inter**: Governs all structural hierarchies, analytical summaries, status messaging, and government reporting. Clear letterforms and standardized geometric shapes ensure effortless scanning across complex tables and spatial overlays.
- **JetBrains Mono**: Strictly utilized for geographic coordinates (Latitude/Longitude), administrative asset codes (Kode Ruas Jalan), fiscal values (Rupiah balances), calculated priority scores (SAW/AHP indices), and sensor metric feeds. Its monospaced rhythm ensures tabular numerals align consistently in high-frequency data streams.

## Layout & Spacing

The system implements a structured 12-column fluid grid system engineered for tactical monitoring matrices and multi-layered spatial cartography:

- **Desktop (1440px and above)**: 12-column layout with fixed 320px left navigation/control drawer, 2rem (`margin`) screen boundaries, and 1.5rem (`gutter`) intra-card separation. Complex GIS dashboards divide the workspace into an 8-column primary map canvas flanked by a 4-column priority matrix and telemetry stream.
- **Tablet (768px – 1439px)**: Collapses into an 8-column layout. The map canvas remains sticky to the upper half of the viewport, with spatial parameter rankings shifting into a responsive 2-column stacked card feed beneath.
- **Mobile (Below 768px)**: 4-column layout with 1rem (`margin-mobile`) exterior padding. Critical KPI cards and score ribbons stack vertically with full-width drawers for field verification teams.

## Elevation & Depth

Visual hierarchy uses physical and luminous layering rather than heavy drop shadows:

- **Layer 0 (Canvas Base)**: Pure `#070B14`, raw background layer housing full-screen geospatial satellite imagery or vector topology.
- **Layer 1 (Surface Panels & Cards)**: Solid `#0E1424` background with a crisp, uniform `1px solid rgba(255, 255, 255, 0.08)` border. Minimal ambient shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
- **Layer 2 (Interactive Modules & Hover Elevators)**: `#141C32` surface with subtle dynamic neon rim lighting corresponding to the respective Strategic Pillar:
  - Pillar 1 hover: `box-shadow: 0 0 20px -5px rgba(16, 185, 129, 0.25), inset 0 1px 0 rgba(16, 185, 129, 0.4)`.
  - Pillar 2 hover: `box-shadow: 0 0 20px -5px rgba(59, 130, 246, 0.25), inset 0 1px 0 rgba(59, 130, 246, 0.4)`.
  - Pillar 3 hover: `box-shadow: 0 0 20px -5px rgba(245, 158, 11, 0.25), inset 0 1px 0 rgba(245, 158, 11, 0.4)`.
  - Alert hover: `box-shadow: 0 0 20px -5px rgba(239, 68, 68, 0.35), inset 0 1px 0 rgba(239, 68, 68, 0.5)`.
- **Layer 3 (Overlays, Flyouts & Modals)**: Frosted command glass using `background: rgba(14, 20, 36, 0.85)`, `backdrop-filter: blur(16px)`, surrounded by `1px solid rgba(255, 255, 255, 0.15)`.
- **Document Detail Sheet Accent**: Inset or popover analytical dossiers adopt a high-contrast `#F8FAFC` foundation with `#0F172A` deep charcoal typography. This delivers an immediate tactile cognitive shift from "live monitoring" to "formal executive audit review."

## Shapes

The design system uses generous, modern radii that soften complex mathematical data matrices while maintaining clean geometry:

- Standard cards, dashboard metrics containers, and GIS floating control heads use `rounded-xl` (1.5rem / 24px) or `rounded-lg` (1rem / 16px).
- Internal form elements, data grid rows, and telemetry chips employ base rounding (0.5rem / 8px).
- Status indicator pills and action trigger chips leverage a fully pill-shaped profile (`9999px`) to distinguish categorical metadata tags from structured card boundaries.

## Components

### Buttons & Action Controls
- **Primary Pillar Buttons**: Dynamic horizontal linear gradients (`#10B981` to `#14B8A6` for approvals/primary actions; `#3B82F6` to `#6366F1` for geo-processing actions). Text styled in Inter semi-bold with matching soft glow on hover.
- **Secondary Ghost Buttons**: Transparent base, `1px solid rgba(255, 255, 255, 0.14)`, text `#E2E8F0`. On hover: border expands to `rgba(255, 255, 255, 0.3)` with background tint `#141C32`.
- **Danger / Override Buttons**: Linear gradient `#EF4444` to `#EC4899`, white text, distinct crimson-magenta drop glow.

### Chips & Metadata Tags
- Built using **JetBrains Mono** for alphanumeric codes (`RUAS-KR-042`, `SKOR: 89.4`, `AHP-RANK: #01`).
- Pill shape with subtle 10% opacity categorical fill matched with a solid 1px border and glowing dot indicator (e.g., green dot with `box-shadow: 0 0 6px #10B981`).

### Lists & Matrix Tables
- Alternating dark rows (`#0E1424` and `#070B14`) bordered by faint hairpins (`rgba(255, 255, 255, 0.04)`).
- Hover transitions highlight rows with a 2px left border strip themed to the route's dominant pillar gradient.
- Coordinates and numeric values right-aligned using tabular figures in JetBrains Mono.

### Input Fields & Selectors
- Background: `#070B14` inset box. Border: `1px solid rgba(255, 255, 255, 0.12)`.
- Radius: `0.5rem`.
- Active focus state: border shifts to `#10B981` with a localized diffuse glow: `0 0 0 3px rgba(16, 185, 129, 0.2)`. Placeholder text formatted in muted slate `#64748B`.

### Checkboxes & Segmented Radios
- Square-rounded (6px) and circular enclosures finished in `#0E1424` with high-contrast active check glyphs illuminated in emerald or indigo. Selected segmented toggles cast an ambient inset gradient glow.

### Cards & Analytical Widgets
- Default: `#0E1424` core fill, 20px internal padding, `rounded-xl` (1.5rem), `1px solid rgba(255, 255, 255, 0.08)`.
- Header section separated by a subtle 1px divider, housing a category-colored accent pill and live calculation timestamp.

### Specialized Component: Executive Detail Sheet (Dokumen Analisis Prioritas)
- A pull-out right-side modal or embedded tab formatted in high-contrast crisp white (`#F8FAFC`).
- Uses slate typography (`#0F172A`) and structured formal borders (`#E2E8F0`) to preview official regional decree (SK Bupati) printouts and technical road budget breakdowns.
